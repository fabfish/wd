## 2. 核心判断：论文缺的是同一个实验

已有的约 1300 次训练**全部是 100 epoch**，`T` 从未变过。这一个疏漏同时导致了
三条主要批评：

- **新颖性**（SijV、xkCF、AC）：在固定 `T` 下，我们的 `λ* = C/(ηT)` 与 Kosson
  等人的 `ηλ = const` 在数值上完全无法区分。只有扫 `T` 才能分开：我们预测
  `log λ*` 对 `log T` 的斜率为 **-1**，平衡态理论预测 **0**。
- **λ 是否冗余**（eC8H）："固定 λ 只调 η" 这个说法只在固定 `T` 时成立。
- **没有基线对比**（xkCF Q3）：跨 `T` 迁移正是最能体现差别的测试场景。

因此全部实验以 **E1（训练长度扫描）** 为锚点，其他实验尽量复用它的结果作为
oracle。

另外我们把定律改写为 **`λ* = C / Σₜηₜ`**（用总步长预算而非 `ηT`）：

- 常数学习率 `Σηₜ = ηT`；cosine 退火到 0 时 `Σₜ 0.5(1+cos(πt/T)) = (T+1)/2`，
  即 `Σηₜ = ηT/2`，于是同一条定律写成 `2C/(ηT)`。
- 这正好解释了 SijV 指出的 Eq.16 的 `1/(ηT)` 与结论处 `2/(ηT)` 的矛盾——
  那不是笔误，是调度差异。改写之后矛盾消失，并且给出一个可验证预测：
  同样的 `η`、`T` 下，常数学习率应当偏好 cosine 一半的 weight decay。

## 4. 已经拿到的真实数字（已写进正文，不是占位符）

来自 Wave 0，全部由已有的 1318 次训练重新分析得到，没有新训练：

**E2a 包络线**（ResNet-18 / CIFAR-100，8×9 网格，两个种子）
- 让 λ 随 η 联动时，准确率在**两个数量级的 η 范围内只波动 2.8 个点**。
- 常用默认值 `λ=5e-4` 平均损失 **1.44 个点**，最差处损失 **3.77 个点**。
- **任何**固定 λ 都做不到更好，最优的固定选择最差处仍然损失 3.77 个点。
- `log λ*` 对 `log η` 斜率 **-0.87，95% 区间 [-0.94, -0.75]**。

**E5a 常数 C**（65 个独立设置：3 种架构 × 5 种 batch size × 2 个种子）
- 几何均值 **C = 1.48**，乘性标准差 **×/1.70**，全范围 0.17–2.99。
- 按架构：ResNet-18 1.42，ResNet-50 1.42，VGG-16 1.72。
- 按 batch size：32→1.38，64→1.89，128→1.40，256→1.60，512→1.71
  （这个残余趋势就是「最优乘积随 B 增长」的诚实版本）。

**E6a 动量**
- 重新调过 η 之后，`λ=0` 时 β∈[0,0.8] 峰值准确率只差 **0.25 个点**；
  `λ=2e-3` 时 β∈[0,0.95] 只差 **1.38 个点**；β=0.99 掉到 73.68%。
- → 直接回答 eC8H：**动量本身不改善泛化，它只是移动最优步长**。
- `log η*` 对 `log(1-β)` 斜率：无 WD 时 1.24 [0.80, 2.32]，有 WD 时
  0.72 [0.58, 0.93]（理论预测 1）。

## 7. 应急预案

万一 E1 的斜率不是 -1：

- 如果落在 -0.5 到 -1 之间：说明 `T` 依赖存在但弱于理论。按测到的值报告，
  论断改成「最优 λ 随训练长度显著下降，指数介于 X 与 -1 之间」，对 Kosson
  的区分依然成立（他们预测 0），只是定量吻合度下降。
- 如果落在 0 附近：我们的核心预测被否证。诚实的做法是把这作为 negative
  result 报告——本文的 Contribution Type 本来就填的是 Negative Results，
  这在叙事上是可以自洽的，但需要重写第 5 节。
- 如果最优 λ 落在扫描网格边缘：先扩网格再下结论，`optimal_wd` 里有
  `interior` 标记可以识别这种情况。

**已经暴露的一个问题（重要）**：E1-prelim 的 λ 阶梯
{1e-4, 5e-4, 1e-3, 5e-3, 2e-2} 相邻间隔达 5 倍，而理论预测 T 从 25 变到 200
只让 λ* 移动约 8 倍。用这么粗的网格去测一个 8 倍的位移，抛物线插值的误差会
和信号同量级。

中间结果（粗阶梯，**勿引用**）：
- T=25：峰值 λ=1e-3（73.78%），插值 λ*≈7.9e-4
- T=100：峰值仍是 λ=1e-3（77.28%），插值 λ*≈7.4e-4
- 粗斜率 ≈ 0 —— 这是网格分辨率假象，不是对理论的否证

因此正式斜率来自 **E1-fine**（密阶梯 {1e-4, 2e-4, 5e-4, 1e-3, 2e-3, 5e-3,
1e-2, 2e-2}，约 2.2 倍间隔，含 T=50）。`nips26_report` 已加护栏：只有密阶梯
到位才填写 `[[E1-T-SLOPE]]`，粗阶梯结果只进 Notes。
