## F1（不采纳）——reviewer 误读，无需改动

reviewer 质疑 Eq.(17) 与 Table 4 在 batch-size 上"矛盾"（一边 `λ*∝B`，一边
`ηλ*` 落在窄区间）。这是误读：我们的主张只有一条律 `λ* = C / Σ_t η_t`。

- **固定 η 时**，`Σ_t η_t ∝ 1/B`，故 `λ* ∝ B`（实测 slope **+1.02 [+0.88, +1.15]**）。
- **线性 LR scaling（η ∝ B）时**，`Σ_t η_t` 被 B 抵消而不变，故 `λ*` 基本不动、
  `ηλ* ∝ B`。
- 不分条件对 65 个设定做裸回归只得到 **+0.23**——两个依赖互相抵消，"条件"正是
  主张的全部内容。
- 已发布的 **C 在 B 上的残余漂移 1.38 / 1.89 / 1.40 / 1.60 / 1.71 与 paper/Table 4
  逐字一致**，不存在矛盾。

因此按 reviewer 要求"明确主张"反而多余，整段删掉。仅自行做一处精确化：
**删掉 Exp.3 中 "optimal `λ` grows with B"，改为"线性 LR scaling 下 `ηλ*` 随 B
增长而 `λ*` 基本不动（`λ*∝B` 是固定 η 下的读法）"**。

## F2（E9）——按 reviewer 给的两个 scheduler

reviewer 指出原 joint-multiplier arm 使 `η_tλ_t = η₀λ₀·m(t)²`，破坏了我们主张的
耦合，不能作为对照。改用他给的两个方案（ResNet-18/CIFAR-100/`B=128`/`η₀=0.1`/
`T=100`/SGDM/**cosine LR**，与正文同设定）。

### (a) iso-product：`λ_t = λ₀·η₀/η_t`（保持 `η_tλ_t` 恒定）

cosine 尾巴 `1/m_cos` 会发散，故乘子上限 clip 到 **10×**（写进协议，非静默）。
`λ₀ ∈ {1e-4, 5e-4, 1e-3, 2e-3, 5e-3}`：

| `λ₀` | 实际 `Σ_t η_tλ_t` | best acc |
|---:|---:|---:|
| 1e-4 | 0.29 C | 75.56 |
| **5e-4** | 1.44 C | **77.98** |
| 1e-3 | 2.88 C | 77.98 |
| 2e-3 | 5.76 C | 70.36 |
| 5e-3 | 14.39 C | 22.13 |

### (b) matched cumulative contraction

按 `Σ_t η_tλ_t` 反解 `λ₀`，使各形状在同一预算 `{C/3, C, 3C}` 下可比
（`C = 1.181` 即本设定规则给定值；`fixed` 形状三档恰好是 E5b 的 wrong-C 点与
E4-ours 基线，**直接复用旧 run**，不重训）：

| budget `Σ_t η_tλ_t` | fixed | cosine | linear | step | **iso-product** |
|---|---:|---:|---:|---:|---:|
| `C/3` | 74.62 | 74.34 | 74.43 | 74.16 | **75.86** |
| `C` | 76.72 | 75.50 | 76.44 | 75.85 | **78.22** |
| `3C` | 76.19 | 75.03 | 75.53 | 73.97 | **77.50** |

结论：

1. **匹配收缩预算不够**：同预算下形状仍差 **1.70 / 2.72 / 3.53 pp**，说明
   `Σ_t η_tλ_t` 不是 schedule 的充分统计量；形状本身也重要。跨预算同形状 spread
   （1.16–2.36 pp）同量级，两因素都不主导。
2. **保持耦合的形状在每个预算都赢**：比同收缩的常数 `λ` 高 **+1.24 / +1.50 / +1.31 pp**。
3. 与同 `η₀`/`T`/优化器下所有 arm 对比，iso-product（matched @ `C`）= **78.22** 是
   测得的最佳臂：比常数 `λ` 的 per-cell oracle（77.28）高 **+0.94**，比 joint
   multiplier（76.42）高 **+1.80**。

→ 收回 joint-multiplier 框架，改用 iso-product 作主对照。

## F3（E10）——held-out C：小 MLP 标定，大 MLP 盲预测

以 MLP **宽度**为 held-out 架构轴（参数量变 4–16×，数据/优化器/调度不变）。
三阶段硬隔断 `ladder → predict → heldout`，`predict` 在跑任何 held-out 网格前把
`λ_pred` 带时间戳落盘（`blind: true`）。h=512 重拟合复现 E5c 的 0.440/0.320。

**C 随宽度（仅标定向）**：

| dataset | momentum | `C(128)` | `C(256)` | `C(512)` | `log C` vs `log h` 斜率 |
|---|---:|---:|---:|---:|---|
| MNIST | 0 | 0.442 | 0.374 | 0.440 | **−0.00 [−0.24, +0.24]** |
| MNIST | 0.9 | 0.466 | 0.353 | 0.320 | **−0.27 [−0.40, −0.14]** |
| CIFAR-10 | 0.9 | — | 2.800 | 2.672 | −0.068（两档，无区间） |

**盲外推 vs 直接测量**：

| dataset | momentum | width | `C` 预测 | `C` 实测 | ratio |
|---|---:|---:|---:|---:|---:|
| MNIST | 0 | 1024 | 0.416 | 0.325 | 1.28× |
| MNIST | 0 | 2048 | 0.415 | 0.327 | 1.27× |
| MNIST | 0.9 | 1024 | 0.257 | 0.244 | 1.05× |
| MNIST | 0.9 | 2048 | 0.213 | 0.255 | 0.84× |
| CIFAR-10 | 0.9 | 1024 | 2.549 | 2.479 | **1.03×** |

C 跨 4–16× 宽度迁移误差 **≤1.3×**；`λ` 误差 MNIST **1.60×** / CIFAR-10 **1.14×**。

**是否省调参**（oracle = 该 cell 内最优 `λ`，含 5 点梯 + 各规则自身 `λ`，故无规则
能靠"梯子粗"占便宜；成本：每 cell 5+ run 给 oracle，规则只要 1 run）：

| dataset | rule | mean acc gap (pp) | worst | mean loss gap | `λ/λ_oracle` |
|---|---|---:|---:|---:|---:|
| MNIST (12 cells) | default 5e-4 | 0.03 | 0.11 | 0.0005 | 1.27× |
| | `1/(ηT)` | 0.11 | 0.25 | 0.0032 | 2.70× |
| | const `ηλ` | 0.06 | 0.20 | 0.0018 | 1.56× |
| | **ours** | 0.08 | 0.19 | 0.0020 | 1.60× |
| CIFAR-10 (3 cells) | default 5e-4 | 0.84 | 1.19 | 0.1576 | 0.13× |
| | `1/(ηT)` | 0.52 | 1.11 | 0.0792 | 0.23× |
| | const `ηλ` | 1.49 | 3.73 | **0.0171** | 1.08× |
| | **ours** | 2.01 | 3.79 | 0.0233 | 1.14× |

诚实结论：

- **`λ*` 预测准，准确率优势没有**：CIFAR-10 上 ours/const-`ηλ` 离 loss-oracle `λ`
  最近（1.1×），但 default 准确率 gap 更小（因该设定 accuracy 最优在更小 `λ`）。
  与 E4（ours 0.87 vs default 0.70）同模式，照实写。
- **MNIST 无法区分**四条规则（全在 0.11pp 内）——负面信息，不声称 MNIST-MLP 上有优势。
- **真正脆弱的不是宽度而是族**：C 在 MNIST-MLP 0.32–0.44、CIFAR-10-MLP 2.5–2.8、
  CIFAR-100 CNN 1.48（几何均值），跨族约 **8.8×**，而 16× 宽度内 ≤1.5×。实用结论：
  每族标定一次，之后跨宽度/η/T 迁移；一次标定替代二维网格，但不替代"知道族"。
- 限制：单 seed；CIFAR-10 梯仅 2 档故斜率无区间；`η=0.3` 时预测 `λ=1.402e-3` 发散
  而 `1.322e-3` 收敛（在稳定性边界），计为发散不插补。
